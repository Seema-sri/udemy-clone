# Udemy Clone Website

## Description
This project is a simple Udemy Clone website created using HTML and basic CSS. It is designed to replicate the basic layout and appearance of the Udemy online learning platform.

The website provides a clean and user-friendly interface to showcase online courses.

## Technologies Used
- HTML5
- CSS3

## Features
- Simple and attractive user interface
- Course recommendations section
- Popular courses section
- Basic webpage styling using CSS

## Purpose
This project was created to practice and improve my frontend web development skills using HTML and CSS.

## How to Run
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser to view the website.
